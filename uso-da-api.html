Uso da YouTube Data API

Página técnica de conformidade · Atualizada em 12 de agosto de 2026 · English version below

Esta página existe para transparência com o YouTube e com clientes que precisam auditar como seus dados são tratados. Não descreve o funcionamento interno do produto.

Endpoints utilizados

EndpointFinalidade
videos.list Verificar quais dos canais acompanhados estão transmitindo ao vivo no momento, e confirmar quando uma transmissão termina
liveChat/messages.list Coletar o chat público das transmissões que o assinante escolheu observar
search.list Resolver qual transmissão está no ar em um canal quando o assinante o abre

Uso responsável de cota

A economia de cota é decisão de projeto, não consequência de pouco uso:

  • Consultas em lote. Pedir um ou cinquenta vídeos custa o mesmo à API, então nunca é feita uma consulta por vez.
  • Cache no servidor, compartilhado. Não é cache por usuário: dois assinantes acompanhando o mesmo canal consomem uma consulta só.
  • Canal fora do ar também é lembrado. Evita repetir consulta sobre quem não está transmitindo.
  • Intervalos de coleta calibrados. Cada mensagem de chat carrega o próprio horário de publicação, então coletar em intervalos maiores não perde precisão nenhuma — só consome menos.

Conformidade

  • Toda reprodução de vídeo acontece pelo player oficial do YouTube.
  • Nenhum vídeo é baixado, re-hospedado, retransmitido ou recodificado.
  • Anúncios e marca do YouTube nunca são removidos ou ocultados.
  • Apenas chat público é coletado, e só das transmissões que o assinante escolheu observar.
  • Mensagens coletadas são apagadas automaticamente após 90 dias.
  • Dados da API não são vendidos, revendidos nem licenciados como produto — nem em forma bruta, nem processada. A assinatura remunera o software, não o dado.
  • Nenhum dado é compartilhado com anunciantes ou corretores de dados.

Aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google. O tratamento de dados pessoais está descrito na Política de Privacidade.

YouTube Data API usage

Compliance reference · Updated August 12, 2026

Endpoints used

EndpointPurpose
videos.list Determine which followed channels are currently live, and confirm when a broadcast ends
liveChat/messages.list Collect public live chat from broadcasts the subscriber chose to monitor
search.list Resolve which broadcast is airing on a channel when the subscriber opens it

Responsible quota use

  • Batched requests. Requesting one or fifty videos costs the same, so lookups are never made one at a time.
  • Server-side cache, shared across users. Not per-user: two subscribers following the same channel consume a single lookup.
  • Offline channels are cached too, avoiding repeated lookups for channels that are not broadcasting.
  • Calibrated polling intervals. Each chat message carries its own publication timestamp, so longer intervals lose no precision — they only consume less quota.

Compliance

  • All video playback occurs through the official YouTube player.
  • No video is downloaded, re-hosted, proxied, or re-encoded.
  • YouTube advertising and branding are never removed or obscured.
  • Only public chat is collected, and only from broadcasts the subscriber chose to monitor.
  • Collected messages are automatically deleted after 90 days.
  • API data is never sold, resold, or licensed as a product, in raw or processed form. The subscription pays for the software, not the data.
  • No data is shared with advertisers or data brokers.
